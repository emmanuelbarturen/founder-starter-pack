# Reglas de Tareas archivadas

- Una tarea llega aquí solo con `/proyectos:archivar`, que confirma dónde quedó su resultado y registra el hito.
- El archivo conserva su nombre: no se le agrega fecha.
- Lo archivado no se edita. Para retomarlo se abre un trabajo nuevo que lo cita.
