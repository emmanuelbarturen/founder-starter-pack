# Reglas de Proyectos archivados

- Un proyecto llega aquí solo con `/proyectos:archivar`, que confirma dónde quedó cada resultado y registra el hito.
- La carpeta conserva su nombre: no se le agrega fecha.
- Lo archivado no se edita. Para retomarlo se abre un trabajo nuevo que lo cita.
